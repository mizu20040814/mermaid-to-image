# Mermaid Web エディタ 仕様

## 目的
ブラウザで Mermaid のコードを書くとその場で図がプレビューされ、PNG または SVG としてダウンロードできる Web 画面を作る。

## 決定事項
- 形態: ブラウザだけで動く静的 Web アプリ（サーバー不要）。描画はブラウザ内で `mermaid` ライブラリが行う。
- 出力形式: PNG と SVG の 2 つ。
- 言語: TypeScript。ビルドは Vite、フレームワークは使わない（素の DOM）。
- 初期セットアップで入れた `@mermaid-js/mermaid-cli` と `puppeteer-config.json` は、ブラウザ内描画になるため削除する。

## 画面
- 左: コード入力欄（`<textarea>`）。初期値は日本語ラベル入りのサンプルフローチャート。
- 右: プレビュー。
- 上部: 「PNG をダウンロード」「SVG をダウンロード」の 2 ボタン。
- プレビューの下: エラー表示欄。
- 幅 768px 未満では入力欄とプレビューを縦に並べる。

## 振る舞い
- 入力が止まってから 300ms 後に再描画する。
- 構文エラーのとき: エラーメッセージを表示し、直前に成功した図はそのまま残す。ダウンロードボタンは無効にする（表示中の図とコードが食い違うため）。
- 入力が空（空白のみを含む）のとき: プレビューを消し、エラーは出さず、ボタンを無効にする。
- 描画が前後して完了しても、最後の入力の結果だけを画面に反映する。
- PNG は白背景、図の 2 倍の解像度で出力する。ただし長辺が 8192px を超える場合は 8192px に収まるよう倍率を下げる。
- ファイル名は `diagram.png` / `diagram.svg`。
- 日本語ラベルが PNG・SVG の両方で表示されること。
